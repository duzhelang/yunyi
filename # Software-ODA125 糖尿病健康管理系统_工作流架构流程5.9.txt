# Software-ODA125 云医智护糖尿病健康管理系统
## 工作流 & 架构 Mermaid 流程图合集

## 一、系统整体架构工作流
```mermaid
flowchart TD
    A[用户访问系统] --> B[Vue3 前端<br/>Vite 5 · 5173端口]
    B -->|HTTP RESTful API| C[SpringBoot 后端<br/>Spring Boot 3.3.5 · 9090端口]

    B --> B1[Login.vue<br/>JWT认证+路由守卫]
    B --> B2[Aside.vue<br/>数据库驱动动态菜单]
    B --> B3[Pinia状态管理<br/>MainStore/HealthStore]
    B --> B4[Axios统一请求封装<br/>Token拦截器]
    B --> B5[15个Composables<br/>组合式函数复用]

    C --> C1[JwtInterceptor<br/>JWT拦截器权限校验]
    C --> C2[30个Controller<br/>169个API接口]
    C --> C3[Service业务逻辑层<br/>ServiceImpl实现]
    C --> C4[MyBatis-Plus 3.5.9<br/>Mapper数据访问层]
    C --> C5[UsePythonUtils<br/>Python子进程调用工具]

    C --> D[MySQL 8.0 数据库<br/>25张业务表]
    C --> E[Redis<br/>Spring Cache缓存]
    C --> F[Python 3.12 算法层<br/>PyTorch 2.11 / SHAP 0.46 / Pandas]
    F --> G[AI大模型服务<br/>智谱GLM-4 / DeepSeek / Kimi / MiMo]
```

## 三、核心预测数据流（单条预测）
```mermaid
flowchart TD
    A[用户录入8项健康指标<br/>怀孕次数/血糖/血压/皮褶厚度/胰岛素/BMI/DPF/年龄] --> B[前端Pinia状态存储<br/>useDraftPersistence草稿缓存]
    B -->|POST /api/predict/single| C[SinglePredictController]
    C --> D[SinglePredictServiceImpl<br/>参数范围校验]
    D --> E[ModelVersionService<br/>获取激活模型路径]
    E --> F[UsePythonUtils.callPythonAndGetOutput<br/>调用predict_single.py · 30秒超时]
    F --> G[Python推理引擎<br/>PyTorch模型 + MC Dropout不确定性估计 + SHAP归因]
    G --> H[返回JSON结果<br/>风险概率/置信区间/特征重要性/图表Base64]
    H --> I[前端ECharts渲染<br/>仪表盘/雷达图/瀑布图/特征柱状图]
    I --> J{用户选择}
    J -->|保存| K[写入user_health_profiles表<br/>生成AI健康建议]
    J -->|跳转问诊| L[携带预测数据至DiabetesChat<br/>上下文感知AI对话]
```

## 五、AI模型在线训练数据流
```mermaid
flowchart TD
    A[管理员上传CSV训练集<br/>或扫描训练目录] --> B[解析入库sys_trainfile表<br/>自动检测数据质量/样本数/列信息]
    B --> C[创建训练任务<br/>配置超参数:学习率/轮次/批大小]
    C -->|POST /api/train-task/start| D[TrainTaskService<br/>@Async异步执行]
    D --> E[调用train.py或incremental_train.py]
    E --> F[Python Pandas数据预处理<br/>缺失值填充/特征缩放]
    F --> G[PyTorch三层全连接网络训练<br/>fc1→fc2→fc3 + Dropout]
    G --> H[输出模型文件.pth + scaler + encoder]
    H --> I[自动注册模型版本<br/>sys_model_version表<br/>记录准确率/损失/F1/AUC]
    I --> J[管理员查看训练指标<br/>混淆矩阵/趋势图/雷达对比]
    J --> K[激活模型版本<br/>供单条/批量预测调用]
```

## 十二、RBAC权限与动态路由工作流
```mermaid
flowchart TD
    A[用户登录] --> B[后端验证用户名密码]
    B --> C[签发JWT Token<br/>含userId+密码签名]
    C --> D[前端存储Token至localStorage]
    D --> E[路由守卫beforeEach触发]
    E --> F{Token有效性校验}
    F -->|有效| G[请求sys_menu表<br/>按角色获取菜单权限]
    F -->|无效/过期| H[重定向至Login.vue]
    G --> I[动态添加路由<br/>router.addRoute]
    I --> J[Aside.vue渲染侧边菜单<br/>数据库驱动 零代码新增页面]
    J --> K[每次API请求<br/>JwtInterceptor拦截校验]
    K --> L{权限判断}
    L -->|通过| M[Controller处理业务]
    L -->|拒绝| N[返回401/403]
```
